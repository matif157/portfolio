# Running SPS CRM\n\n## XAMPP (recommended for Windows)\n1. Install/enable PHP 8.1+ and MySQL with PDO MySQL.\n2. Copy the project folder into `C:\\xampp\\htdocs\\SPS_CRM_Professional_2026`.\n3. Copy `.env.example` to `.env`.\n4. Set a random `APP_KEY`; leave AI/voice/SMS/WhatsApp disabled until their providers are configured.\n5. Start Apache and MySQL in XAMPP.\n6. Import SQL files in this order: `00_create_database.sql`, `01_schema.sql`, `01b_extended_schema.sql`, `02_permissions_seed.sql`, `03_service_catalog_seed.sql`, `04_legacy_staging.sql`, `05_workflow_seed.sql`, `06_legacy_views.sql`, `07_admin_seed.sql`, `08_service_automation_seed.sql`, `09_service_source_policy.sql`, `10_reporting_views.sql`.\n7. Run `php database/seed.php` once.\n8. Browse to `http://localhost/SPS_CRM_Professional_2026/` or use the direct `login.php` wrapper if your Apache rewrite is not enabled.\n\n## Built-in PHP server\nDouble-click `start-local.bat`, then open `http://127.0.0.1:8000/index.php?route=%2Flogin`.\n\n## Login\nSeeded administrator: `admin` / `ChangeMeImmediately!123`. Change it immediately.\n\n## Cron\nRun `php cron/run.php` on a schedule (Task Scheduler on Windows or cron on Linux).\n\n## Integrations\nNo external provider is claimed as connected. Configure AI, email, SMS, WhatsApp, voice, payments and authority adapters only after credentials, caller IDs, consent and applicable legal/compliance requirements are in place.\n

## XAMPP subfolder mode
Place the project in `C:/xampp/htdocs/SPS_CRM_AI_Professional_Complete` (or any folder under htdocs), leave `APP_URL` blank, start Apache and MySQL, then open `http://localhost/<folder>/`. Assets are routed to the `public/assets` directory automatically.

## PHP built-in server
From the `public` directory run `php -S 127.0.0.1:8000 index.php` and open `http://127.0.0.1:8000/login`.
