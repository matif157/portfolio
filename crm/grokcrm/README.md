# mera_crm — Modern 2050 Theme Pack

## Features

1. **Futuristic dark UI** — glass panels, cyan/violet glow, modern typography
2. **Full sidebar navigation** — Customizer, Error Logs, Services, Client Types all visible
3. **Invoice template ON the view page** — you see the real invoice layout when viewing an invoice (not only on print)

## Install (3 files)

| Copy this | To |
|-----------|-----|
| `assets/css/crm2050.css` | `assets/css/` |
| `includes/header.php` | `includes/header.php` (replace) |
| `invoices/view.php` | `invoices/view.php` (replace) |

Hard-refresh browser (Ctrl+F5) after upload.

## Requirements

- Previous modules installed (clients, invoices, customizer, error_logs, etc.)
- `includes/settings_helper.php` for company info on invoice
- `invoices/print.php` for dedicated print page

## Navigation now includes

Main: Dashboard · Clients · Invoices  
Finance: Banking · Cards · Reports  
Ops: Services · Reminders · Warnings · Client Types  
System: Customizer · Users · Roles · Activity Logs · Error Logs
