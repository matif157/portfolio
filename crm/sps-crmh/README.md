# SPS CRM

Full-featured professional services CRM with AI assistant, voice integration, omnichannel communication, and 60+ modules.

## Features

- **Client Management** — Full CRUD with search, filtering, and contact history
- **Invoice System** — Create, view, and track invoices with payments
- **Service Automation** — Automated workflows for service delivery
- **AI Assistant** — AI-powered client briefings and recommendations
- **Voice Assistant** — Twilio-based voice communication
- **Omnichannel** — Email, SMS, WhatsApp, and voice from one dashboard
- **Calendar** — Appointment scheduling with reminders
- **Bank Statements** — Import and track bank statements
- **Project Management** — Track projects and tasks
- **Lead Management** — Capture and nurture leads
- **Document Management** — Upload and organize client documents
- **Activity Logs** — Complete audit trail of all actions
- **Role-Based Access** — Admin, manager, and agent roles
- **Multi-Theme** — 5 built-in CSS themes

## Tech Stack

- PHP 8.1+
- MySQL 8.0 / MariaDB
- Bootstrap 5
- Twilio SDK
- HTML/CSS/JavaScript

## Installation

1. Clone the repository
2. Create database and import `crm.sql`
3. Configure `config.php` with your database credentials
4. Start your local server (XAMPP, Laravel Herd, etc.)
5. Login with `admin` / `ChangeMeImmediately!123`
