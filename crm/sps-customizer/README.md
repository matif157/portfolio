# SPS CRM Customizer

Module customization and extension framework for SPS CRM systems.

## Features

- **Module System** — Plugin architecture for extending CRM
- **Custom Fields** — Add custom data fields to entities
- **Theme Support** — UI customization capabilities
- **API Hooks** — Integration points for external services

## Tech Stack

- PHP
- MySQL
- JavaScript

## Installation

1. Clone the repository
2. Import the database schema
3. Configure database credentials
4. Start your local server
