# Softwares — CRM Systems

Collection of 22 CRM software projects built with PHP/MySQL (flat-file, procedural,
MVC and enterprise architectures), featuring AI assistants, banking automation,
invoicing, club management, and role-based access.

Projects (in `crm/`):

| Project | Description |
|---|---|
| `claude-crm` | Flat-file PHP CRM built with Claude AI — clients, invoices, leads, services, calendar |
| `sps-ai-crm-enterprise` | Enterprise AI CRM — 95-table schema, multi-tenant MVC architecture |
| `gpt3-crm` | GPT-iteration CRM — MVC, service operations, bank automation |
| `grokcrm` | Dark-theme CRM with banking, cards, and modern UI |
| `mera-crm` | Experimental CRM — AI copilot, self-healing, vector search, security tools |
| `syed-professional-crm` | Production CRM for professional services |

| `sps` | Early SPS CRM |

## Cleanup note

Third-party libraries (vendor, Twilio, dompdf, ckeditor, PHPMailer, Stripe), client
uploads, generated invoices/quotations, SQL dumps, CSV exports, env files, logs and
backups have been stripped. Configure your own database credentials and dependencies
per each project's README.
