# SPS CRM Invoice Template

Invoice rendering is provided by `invoice_view.php`.

The invoice is:
- itemized
- client-linked
- balance-aware
- print-ready
- browser PDF compatible via **Print / Save PDF**
- visually consistent with the SPS 2050 theme

Files:
- `invoice_create.php` — multi-line invoice entry
- `invoices.php` — invoice command center
- `invoice_view.php` — printable invoice
- `payments.php` — payment ledger
- `assets/css/invoice-print.css` — A4 print rules
