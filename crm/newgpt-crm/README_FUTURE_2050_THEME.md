# SPS CRM — FUTURE 2050 VISUAL SYSTEM

This package adds a modern, futuristic visual layer to the existing CRM without changing the database workflow.

## What changed

- Unified futuristic dark-glass visual system
- Responsive cards, tables, forms and modals
- Module-specific visual labels
- Dashboard command-center styling
- Service orchestration styling
- Bank-statement document-flow styling
- Automation control-center styling
- Reports intelligence styling
- Administration/control-plane styling
- Login and password-setup visual upgrade
- Lightweight vanilla JavaScript enhancement
- No Node/npm/build process required

## Important

The theme is intentionally shared so every module stays visually consistent. Existing PHP/database logic is preserved.

Main theme:
`assets/css/future-theme.css`

UI enhancement:
`assets/js/future-ui.js`
