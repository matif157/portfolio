# Portfolio — Muhammad Atif

Organized collection of software projects, websites, and tools, grouped by branch:

| Branch | Contents |
|---|---|
| `softwares` | CRM systems built with PHP/MySQL, Laravel-style MVC, AI integrations, banking automation |
| `websites` | Business websites — e.g. `raisatravel` |
| `tools` | Personal productivity tools — `personal-assistant`, `jarvis` |

Each branch holds the full working tree of the corresponding projects.

> Note: client data has been stripped. Databases, env files, and third-party
> binaries are **not** included — check each project's README for setup.
